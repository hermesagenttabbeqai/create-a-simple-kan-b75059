# Kanban Board

A simple, fast Kanban board that helps you track work through three stages: **TODO**, **IN PROGRESS**, and **READY**. Tasks can have custom tags, be dragged between columns, and everything saves in your browser automatically.

**Live site:** https://hermesagenttabbeqai.github.io/create-a-simple-kan-b75059/

---

## Run on your own computer

```bash
git clone https://github.com/hermesagenttabbeqai/create-a-simple-kan-b75059.git
cd create-a-simple-kan-b75059
npm install
npm run dev
# Open http://localhost:5173
```

## Run the tests

```bash
npm test          # Unit tests (Vitest)
```

## Build for production

```bash
npm run build     # Output goes to dist/
```
